# bach_check: what Bach (1990) does and does not contain

Source: E. Bach, *Explicit bounds for primality testing and related problems*, Math. Comp. 55 (1990) 355–380
(`~/Documents/bach_1990.pdf`). Method of this check: the whole paper (pp. 355–380) was read through the PDF's
OCR text layer; the pages carrying the statements quoted below (pp. 364, 372, 373, 374, 377) were additionally
read as page images and the quotes/table entries checked against them. Table 3 (p. 378, number fields) was read
only in the (garbled) OCR layer; it is not relevant to the rational case.

## Verdict

**Partially.** Bach already has constants below 2 for the Miller / Solovay–Strassen application, namely
(i) asymptotically 1 + o(1), and (ii) explicit tables (C₁ log m + C₂)² with C₁ → 1. All of this is for an
arbitrary proper subgroup via ONE nonprincipal character. He has nothing using the index of the subgroup,
nothing averaging over several characters, and no constant below 1. The index ≥ 4 results of `miller4.md`
(c∞ ≈ 0.64; c = 0.70 for n ≥ 10¹²–10¹⁵) are not in Bach.

## Exact statements

* Abstract (p. 355): "The bounds imply that if the ERH holds, a composite number m has a witness for its
  compositeness (in the sense of Miller or Solovay-Strassen) that is at most 2 log² m."
* Introduction (p. 356): "In the author's dissertation [5], an explicit constant of "2" for Ankeny's theorem was
  proved. No constant for the second theorem has heretofore been published; we show below that "3" suffices. In
  addition, we show that both theorems hold with a coefficient of 1 + o(1), and tabulate bounds that are close to
  the asymptotic value."
* Same page: "for instance, in testing m for primality, one would be happy to find a nontrivial divisor of it."
  (i.e. the coprimality requirement is unnecessary for primality testing; Theorem 2 / Table 1 is the relevant
  one, not Theorem 3 / Table 2.)
* **Theorem 1 (ERH)** (p. 364): "For i = 1, 2, ... let K_i be a number field whose discriminant has absolute value
  Δ_i, with a nonprincipal character χ_i defined modulo f_i. Let p_i be a prime ideal of minimal norm such that
  χ_i(p_i) ≠ 0, 1 and deg p_i = 1. Assume that Δ_i N f_i → ∞ as i → ∞. Then N p_i ≤ (1 + o(1)) log²(Δ_i² N f_i)."
  For K = Q this is: least n with χ(n) ≠ 0, 1 is ≤ (1 + o(1)) log² m. Proof: kernel x^s/(s+a)², constant
  (1+a)⁴/(2a+1)², a → 0. One character only.
* **Theorem 2 (ERH)** (p. 372): "Let G be a nontrivial subgroup of Z/(m)* such that n ∈ G for all positive n < x.
  Then x < 2(log m)²." Proof opens: "Without loss of generality, G is maximal. There is then a nonprincipal
  character χ with G ⊂ kernel(χ), and it will suffice to assume that χ(n) = 1 for all n < x." So any index
  information is discarded at the first line. (a = 1/2, m ≥ 1000.)
* **Theorem 3 (ERH)** (p. 372): same with "for all positive n < x relatively prime to m. Then x < 3(log m)²."
* Primality consequence (pp. 372–373): "First, if the ERH is true, then a composite number m has a witness for
  its compositeness (in the sense of [30 or 43]) that is at most 2 log² m. Second, if the ERH is true, then
  Z/(m)* is generated by the numbers less than 3 log² m that are relatively prime to m." ([30] = Miller,
  [43] = Solovay–Strassen.) This is the only primality-specific statement. Lehmann's test, strong liars, the
  structure of the liar subgroup, and its index are not mentioned anywhere. [45] Velu is cited only in the
  introduction list of ERH primality tests.
* p. 373: Lemma 6.1 "implies bounds of the form x ≤ (C₁ log m + C₂)², valid for all m ≥ m₀", with
  C₁ = (a+1)²/(2a+1) · (1 + r(x₀)), C₂ = (a+1)² [ t(x₀)(1 + r(x₀))/(2a+1) + s(x₀) ].
* p. 374: "These computations, and the computations used to verify Theorem 3 for small m, showed that in
  Theorem 2, one can replace "2" by 2/log² 3 = 1.657071..., which is the best possible constant." (best possible
  as a constant valid for ALL m; attained at m = 3.)

## What Table 1 amounts to as a constant c in x ≤ c log² m (my arithmetic, −1 ∈ G column)

(C₁ log m + C₂)²/log² m, evaluated at m = m₀ and at the next tabulated m₀ (the sup over the interval, since
C₂ < 0 makes the ratio increasing in m):

| row m₀ | at m₀ | at next row's m₀ |
|---|---|---|
| 10³ | 0.669 | 0.936 |
| 10⁶ | 0.722 | 0.901 |
| 10⁸ | 0.765 | 0.883 |
| 10¹⁰ | 0.799 | 0.972 |
| 10¹⁵ | 0.856 | 0.952 |
| 10²⁰ | 0.890 | 1.082 |
| 10⁵⁰ | 0.965 | 1.042 |
| 10¹⁰⁰ | 0.991 | 1.034 |
| 10⁵⁰⁰ | 1.010 | 1.020 |
| 10¹⁰⁰⁰ | 1.008 | → C₁² = 1.018 |

At m = 10¹² (row 10¹⁰): 0.883 log² m. So Bach's tables already give, for the Miller witness, roughly
0.80–1.08 · log² m pointwise in the tabulated range and ≤ 1.09 · log² m uniformly for m ≥ 10¹⁰ by chaining rows;
the pointwise values below 1 come from the negative C₂ (lower-order term), not from a leading constant below 1.
No row gives a constant below 1 valid for all m ≥ m₀, and C₁ ≥ 1.009 always.

## Dependence on the index

None. Search of the full text for "index" finds only the "index set I ⊂ {1, 2, 3}" of options in §7 (p. 374).
The only structural refinement of G that Bach uses is the parity of the character (−1 ∈ G vs −1 ∉ G, the β
parameter), which affects only C₂ and lower-order terms. Theorem 1's condition χ(p) ≠ 0, 1 is a statement about
one character, not about index. The closing remark of §4 (p. 365) notes only that a weaker zero-free strip
would still give a polynomial bound and that a Siegel zero "would improve the ultimate bound".

## Consequence for miller4.md

* §1 of `miller4.md` should not say that every published Miller bound is 2 log² n: Bach himself gives
  (1 + o(1)) log² n (Theorem 1, intro p. 356) and Table 1, e.g. x ≤ (1.170 log m − 6.364)² for m ≥ 10¹⁰.
* The claim "no published bound with c < 1" survives as far as Bach 1990 is concerned (leading constant), with
  the caveat that Table 1 gives pointwise ratios below 1 for m up to about 10²⁰–10¹⁰⁰ through the negative C₂.
  The fair comparison at n = 10¹² is 0.70 (miller4) against 0.883 (Bach Table 1, row 10¹⁰), and at n → ∞
  0.64 against 1.
* The index ≥ 4 mechanism, several characters, and any c∞ < 1 are new relative to Bach 1990.
